# Contributing to Team Expense Management System

Thank you for contributing to this project.

## Development Workflow
1. Ensure Java 17+ and Node.js 18+ are installed.
2. Fork the repository and create a feature branch (`git checkout -b feature/new-capability`).
3. Follow the clean layered architecture (`Controller -> Service -> Repository`).
4. Run all backend tests (`mvn test`) and ensure frontend builds (`npm run build`).
5. Submit a pull request describing your improvements.
